# طرح بازنویسی v0.70.0-beta — «مغز واحد + حافظه» (نسخهٔ ۲ — معماری AI-First)

> نسخهٔ ۲ طرح، پس از تصمیم کاربر: «منطق اصلی پای جمینای باشه؛ خودش تحلیل کنه چی میگه، چیو ذخیره کنه، چیو بنویسه — ما کلمات رو جدا جدا با گرامر تحلیل نکنیم.»
> وضعیت: ⏳ در انتظار تأیید نهایی — هیچ کدی هنوز نوشته نشده.

## تصمیم معماری: AI تصمیم می‌گیرد، کد صحه می‌گذارد و اجرا می‌کند

**مشکل ریشه‌ای نسخه‌های قبل:** لایهٔ گرامرِ قطعی (regex) «تصمیم‌گیر» بود — msgParse روی جملهٔ آموزشی فایر می‌شد، type-once حریص تایپ می‌کرد، مقصدِ «همین اسم» لفظی سرچ می‌شد. این‌ها با وصلهٔ regex تمام نمی‌شوند (۱۲ ریشهٔ لاگ ثابت کرد).

**معماری جدید — سه لایهٔ ساده:**

```
صدا → [لایه ۱: Fast-Path بی‌ابهام]  → اجرای آنی آفلاین (باز کردن اپ، صدا، URL، پلیر)
     → [لایه ۲: مغز واحد — یک فراخوان Gemini]  → تصمیم JSON سخت‌ساختار
     → [لایه ۳: صحه‌گذار + اجرا]  → چک اعتبار → act → شاهد یا سکوت
```

- **لایه ۱ (Fast-Path):** فقط کارهای قطعیِ بی‌ابهام که آفلاین هم باید فوری باشند: باز کردن برنامه با دیکشنری تلفظ، صدا/مدیا، ساعت/تاریخ، URL لخت، کنترل پلیر با عبارت‌های صریح. **هیچ تصمیم معنایی‌ای اینجا گرفته نمی‌شود.**
- **لایه ۲ (مغز واحد):** همهٔ جمله‌های معنایی — پیام، یادداشت، ذخیره/یادت‌باشه/آموزش، سوال، گفتگو، ارجاع («همین که گفتم») — **یک فراخوان AI** با: تاریخچهٔ جلسه (۶ رد و بدل آخر) + فکت‌های حافظه + مخاطبین + موجودیت‌ها. خروجی: JSON اجباری:
  ```json
  {"speak":"جواب صوتی کوتاه",
   "actions":[{"act":"contact_save","params":{"app":"telegram","nameFa":"میلاد قدوسی","nameEn":"Milad Ghodousi"}},
              {"act":"memory_save","params":{"text":"هر وقت گفتم به میلاد پیام بده → چت میلاد قدوسی تلگرام"}}],
   "confirm":"بذار به میلاد قدوسی (Milad Ghodousi) تو تلگرام بگم «چطوری»؟",
   "clarify":null}
  ```
  فکر/تحلیل داخل خود مدل است — دیگر خط «interpret» جدا و دوباره‌کاری حذف می‌شود (باگ interpret دوگانهٔ لاگ همین‌جا ریشه‌کن می‌شود).
- **لایه ۳ (صحه‌گذار):** کد فقط چک می‌کند: act در whitelist؟ پارامترها کامل؟ مخاطبِ انتخاب‌شده واقعاً در لیست هست (نه حدس مدل)؟ متن پیام خالی/آلوده نیست؟ اگر نه → سوال شفاف‌سازی یا فالبک صادقانه. سپس اجرا با «شاهد یا سکوت» (UIA).

**معاملهٔ صادقانه:** فرمان‌های ساده همان سرعت قبل را دارند (Fast-Path). جمله‌های معنایی ~۱-۳ ثانیه تحلیل AI می‌خورند — دقیق‌تر، به‌جای سریع‌ولغتان. کاربر خودش این معامله را پذیرفته.

## فاز ۰ — هستهٔ حافظه (پایهٔ همه‌چیز)

- `ava-memory.json` پایدار در userData: `facts[]` (یادت‌باشه‌ها، قواعد آموزشی) + `contacts[]` (nameFa/nameEn/app/handle/source) + `notes[]` (text/lang/createdAt) + جلسهٔ زنده (turns تا ۲۰ + موجودیت‌ها)
- فالبک آفلاین: اگر شبکه نبود، فکت‌ها/مخاطبین به فرمان‌های آموخته‌شدهٔ voiceLearn اضافه می‌شوند تا حداقل «به میلاد پیام بده» آفلاین هم کار کند.

## فاز ۱ — مغز واحد (جایگزین مسیربینی گرامری)

- حذف از مسیر تصمیم: msgParse، type-once حریص، notes-re، CTX-resolve دستی («همین»→last) — این‌ها به لایهٔ صحه‌گذاری منتقل می‌شوند یا حذف.
- پرامپت سیستم بازنویسی کامل: پروتکل THINK ساده‌سازی می‌شود به «اول تحلیل کن، بعد JSON بده» + قانون‌های طلایی فعلی (قانون ۵ درون-سایت، ۸ ضدتوهم research، type_once دقیق، video_ctl) عیناً حفظ — فقط قالب خروجی به JSON اجباری تغییر می‌کند.
- ایزوله‌سازی تاریخچه: سلام/حال/چتِ ساده تاریخچهٔ موضوعی نمی‌گیرد (باگ «خوبی→دودو»).
- تزریق هوشمند: آخرین ۶ turn + فکت‌های مرتبط با کلیدواژه + مخاطبین — نه dump خام.

## فاز ۲ — پیام‌رسان با شاهد (رفع ریشه‌های ۱، ۳، ۴)

- تلگرام: **Ctrl+K** گلوبال + خواندن نتایج با UIA + تطبیق دقیق/لوانشتین + باز کردن + راستی‌آزمایی تیتر با UIA + ارسال + خواندن پیام ارسالی → فقط با شاهد `OK:MSGSENT`
- مقصد همیشه از contacts (AI شناسهٔ مخاطب را انتخاب می‌کند، کد وجودش را صحه می‌گذارد)؛ مخاطب نبود → `confirm`/`clarify` — هرگز سرچ لفطیِ «همین اسم»
- متن پیام از خروجی AI می‌آید (مدل دنبالهٔ دستوری را از متن جدا می‌کند — باگ «چطوری اسمشو انگلیسی بنویس» به‌عنوان متن)؛ صحه‌گذار فقط خالی‌نبودن و طول را چک می‌کند
- دیسکورد/واتساپ/بله/روبیکا با همان قرارداد

## فاز ۳ — تلفظ↔لاتین

- دیکشنری محلی (سلفون→cellphone، نام‌های رایج) برای Fast-Path و سرچ سریع + AI خودش در JSON نام لاتین می‌سازد (transliterate داخلی) → ذخیرهٔ دوفرمی مخاطب

## فاز ۴ — یادداشت حرفه‌ای

- ذخیرهٔ ساخت‌یافته + انگلیسی‌سازی در خواست کاربر + بازخوانی قطعی («یادداشت‌مون رو نشون بده» بدون AI) + ویرایش/حذف + پنل UI

## فاز ۵ — سرعت و پایداری

- تک‌فراخوان به‌جای interpret+DO (حذف دوباره‌کاری لاگ‌شده) + بودجهٔ ۱۲ ثانیه‌ای هر دور + استریم پاسخ + زنجیرهٔ فالبک GLM/OpenAI + search وب فقط با نیاز واقعی + کاهش نویز wake (آستانهٔ انرژی + لاگ تجمیعی)

## فاز ۶ — صحه‌گذاری و ریلیز

- `scripts-test-v0700.js`: صحه‌گذار JSON (whitelist/پارامترها)، Fast-Path (اپ/صدا/URL)، TEACH مسیرآموزش از عین جمله‌های لاگ کاربر، CRUD حافظه/مخاطب/نوت، گارد‌های پیام‌رسان
- باتری کامل سوئیت‌های قبلی (forward-relax پین‌ها) + اسموک Xvfb + node --check
- بامپ 0.70.0-beta، README، کامیت، تگ، CI، انتشار، راستی‌آزمایی دانلود ناشناس

## معیار پذیرش (روی عین جمله‌های لاگ خودت)

1. «از این به بعد هر وقت گفتم به میلاد پیام بده…» → ذخیرهٔ مخاطب + قاعده + «حفظ شد» — صفر ارسال
2. «به میلاد پیام بده چطوری» (بعد از ذخیره) → Ctrl+K → چت میلاد قدوسی → ارسال با شاهد
3. «یادت باشه فلانی علی چیه» → ۱۰ دقیقه بعد «علی چیه؟» → جواب درست
4. «به انگلیسی یادداشت کن علی اچ کی» → نوت "Ali-HK" + بازخوانی صوتی درست
5. «به همین اسم پیام بده» → مخاطبِ حافظه یا سوال — هرگز سرچ لفطی
6. «خوبی» → جواب گرم ساده — نه ادامهٔ موضوع قبلی
7. فرمان‌های ساده (باز کن/صدا/URL) همان سرعت قبل یا سریع‌تر
