# آوا — دستیار صوتی ویندوز (AVA Voice Assistant)

نسخه **۰.۶** دستیار صوتی ویندوز، ساخته‌شده با **Electron** — با **تشخیص گفتار رایگان گوگل (بدون هیچ کلیدی)**، **چت با GLM متصل به حساب z.ai تو (بدون کلید API)**، **پاسخ تحلیلی به سوالات پیچیده**، **آپدیت خودکار داخل برنامه**، **اکولایزر با صدای واقعی میکروفون** و **تنظیمات کامل میکروفون**.

> در نسخه ۰.۶:
> 1. **دیگه هیچ کلیدی لازم نیست!** تشخیص گفتار فارسی حالا با **موتور رایگان گوگل** انجام می‌شود: زنجیره‌ی موتور وب → **موتور گوگل HTTP** (ضبط PCM ۱۶kHz + تشخیص سکوت VAD + ارسال مستقیم به سرور گفتار گوگل با کلید عمومی کرومیوم). اگر گوگل در منطقه‌ات ۴۰۳ داد، فیلترشکن روشن کن یا کلید اختصاصی (اختیاری) در تنظیمات بگذار.
> 2. **چت بدون کلید API:** در صفحه «چت با هوش مصنوعی» تب «صفحه چت GLM» را باز کن و یک بار وارد حسابت شو (chat.z.ai داخل خود برنامه، نشست دائمی می‌ماند). بعد «چت سریع آوا» و دستیار صوتی هم از همان حساب استفاده می‌کنند — کاملاً بدون توکن.
> 3. **سوال پیچیده؟ جواب از GLM:** هر چیزی که فرمان محلی نباشد، خودکار به GLM می‌رود، تحلیل می‌شود و جواب کوتاه فارسی (گفتاری + متنی) می‌گیری. اگر درخواستت قابل تبدیل به فرمان باشد، کارت تأیید می‌آید و با یک کلیک به فرمان‌ها اضافه می‌شود.
> 4. **انتشار یک‌کلیکی:** فایل `runmetocreateexeforyou.bat` را دابل‌کلیک کن — خودش پوش می‌کند، تگ می‌زند و بیلد EXE در GitHub Actions شروع می‌شود.

## ویژگی‌های این نسخه

- طراحی **Liquid Glass / Fluent** تیره با رنگ تأکیدی زمردی — حس نرم‌افزار دسکتاپ واقعی، نه وب‌سایت
- **پنجره شناور حدود یک‌سوم صفحه** (گوشه راست دسکتاپ) با CSS واکنش‌گرای اختصاصی برای همین سایز
- **تشخیص گفتار واقعی زنجیره‌ای و رایگان:** موتور وب (fa-IR) → **موتور گوگل HTTP** (کلید عمومی کرومیوم، بدون ثبت‌نام) → GLM-ASR (اختیاری، با کلید) — با تشخیص سکوت (VAD)؛ بدون هیچ حالت دموی جعلی
- **چت با هوش مصنوعی GLM بدون کلید API:** تب «صفحه چت GLM» (webview داخلی chat.z.ai با نشست دائمی `persist:ai`) + تب «چت سریع آوا» با حافظه گفتگو — لاگین گوگل/OAuth داخل برنامه پشتیبانی می‌شود
- **پاسخ تحلیلی به سوالات پیچیده:** فرمان شناخته‌نشده → GLM جواب می‌دهد (متنی + گفتاری) و اگر فرمان جدید لازم باشد، با مودال تأیید به لیست اضافه می‌شود
- **ساخت فرمان سفارشی:** فرمان‌های ساخته‌شده با AI به‌صورت chip زمردی در لیست می‌آیند و با صدا/متن اجرا می‌شوند (اسکریپت‌ها فقط با مودال تأیید صریح)
- **آپدیت خودکار داخل برنامه** (electron-updater): بررسی هنگام شروع، نوار پیشرفت دانلود و «نصب و راه‌اندازی مجدد» از صفحه تنظیمات
- **اکولایزر همیشه‌واقعی:** میکروفون از شروع برنامه فعال است و ویژوالایزر ۵۲ میله‌ای به صدای واقعی واکنش نشان می‌دهد
- **پاسخ گفتاری (TTS):** آوا جواب‌ها را بلند می‌خواند؛ انتخاب صدای گوینده (فارسی اگر نصب باشد)
- **ضبط واقعی صدا:** فرمان «شروع ضبط» / «توقف ضبط» — فایل webm در `Music/AVA` ذخیره می‌شود
- **تنظیمات میکروفون:** انتخاب ورودی از لیست دستگاه‌ها + تست زنده با میتر میله‌ای
- **صفحه تنظیمات کامل:** همیشه‌روون، اجرای خودکار با ویندوز، موتور تشخیص گفتار، کلید اختصاصی گوگل (اختیاری)، کلید GLM (اختیاری)، مدل چت، حالت دمو (اختیاری)، بررسی خودکار آپدیت
- کاملاً **فارسی و راست‌به‌چپ** با فونت وزیرمتن (باندل‌شده، آفلاین)
- **اورب صوتی** با هسته‌ی مایع متحرک، حلقه‌های پالس و ویژوالایزر موج صدا (Canvas)
- **نوار عنوان سفارشی Frameless** با دکمه‌های — □ × (کاملاً متصل به Electron با IPC)
- **سایدبار آیکونی** با تولتیپ فارسی و بخش چت فعال
- **نوار وضعیت** زنده: میکروفون، موتور گفتار، CPU / RAM، ساعت
- کادر فرمان متنی + فرمان‌های سریع + کارت پاسخ با افکت تایپ
- میانبر سراسری **Ctrl+Shift+Space** برای شروع/توقف گوش دادن (فقط داخل برنامه اجرا می‌شود)
- در Electron آمار CPU/RAM **واقعی** است (از طریق IPC از پروسه‌ی اصلی)

## انتشار روی گیت‌هاب + دانلود کاربران از Releases (فقط یک دابل‌کلیک!)

### راه ۱ — فایل جادویی (پیشنهادی)

روی ویندوز، فایل **`runmetocreateexeforyou.bat`** را دابل‌کلیک کن. خودش:

1. پروکسی خراب گیت را پاک می‌کند (درس ارور port 443)
2. remote را چک و اصلاح می‌کند
3. همه تغییرات را کامیت و پوش می‌کند
4. اگر تگ نسخه قبلاً استفاده شده، **خودش نسخه را بامپ می‌کند** (۰.۵.۰ ← ۰.۵.۱) — یعنی دیگر هیچ‌وقت تناقض version/tag پیش نمی‌آید
5. تگ می‌زند و پوش می‌کند ← **GitHub Actions خودش EXE می‌سازد** و در Releases می‌گذارد

### راه ۲ — اسکریپت پاورشل

اسکریپت `push.ps1` همه‌ی کارها را خودکار می‌کند:

- اصلاح خودکار فیلد `repository` در `package.json` از روی remote گیت‌هاب ← رفع خطای معروف `Cannot detect repository by .git/config`
- سینک خودکار ورک‌فلو CI (`.github/workflows/build.yml`) و `.gitignore` به ریشه ریپو
- عدم ترک‌کردن `node_modules` و `dist`
- کامیت (اگر پیام ندهی، تاریخ و ساعت می‌گذارد)، pull و پوش
- با سوییچ `-Release`: تگ‌زدن نسخه از روی `package.json` (مثلاً `v0.3.0`) ← بیلد خودکار نصب‌کننده و انتشار در GitHub Releases

### پوش عادی (هر روز)

```powershell
.\push.cmd "پیام تغییرات"
```

### انتشار نسخه جدید (بیلد خودکار + قرار گرفتن EXE در Releases)

```powershell
.\push.cmd "نسخه جدید" -Release
```

حدود ۵ دقیقه بعد، نصب‌کننده در این آدرس برای همه قابل دانلود است:

```
https://github.com/pvwvuow/ava-voice-assistant/releases/latest
```

از نسخه ۰.۴ به بعد، **برنامه نصب‌شده خودش آپدیت می‌شود**: با هر تگ جدید، کاربران فقط پیام «نسخه جدید آماده است» را می‌بینند و با یک کلیک نصب می‌کنند.

> نکته‌ها:
> - از `push.cmd` استفاده کن (خودش ExecutionPolicy را دور می‌زند). اگر مستقیم `push.ps1` می‌زنی و خطای policy گرفتی، یک‌بار `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned` را اجرا کن.
> - اگر ورک‌فلوی دیگری در `.github/workflows` ریپو داری، حذفش کن تا دوبار بیلد نشود (اسکریپت هم هشدارش را می‌دهد).
> - راه‌اندازی یک‌باره (فقط اگر ریپو/remote نداری):
>   ```powershell
>   git init
>   git remote add origin https://github.com/pvwvuow/ava-voice-assistant.git
>   ```

## نحوه‌ی کار کردن پل Electron (برای توسعه‌ی بعدی)

در `preload.js` این API در اختیار UI گذاشته شده (`window.ava`):

```js
ava.window.minimize() / toggleMaximize() / close()      // کنترل پنجره
ava.system.stats() / run(id, arg) / openUrl(u) / saveAudio(buf) / info()
ava.settings.flags() / setAlwaysOnTop(on) / setLoginItem(on)   // تنظیمات سیستمی
ava.updater.check() / install() / setAuto(on) / onStatus(cb)   // آپدیت خودکار
ava.ai.zaiChat({token, messages})                        // چت GLM بدون کلید — با نشست حساب z.ai
ava.ai.chat({base, key, model, messages})                // چت GLM با کلید API (اختیاری)
ava.stt.google({pcm, rate, key?, lang})                  // موتور رایگان گوگل (PCM ۱۶kHz)
ava.stt.transcribe({buf, base, key, model})              // GLM-ASR (اختیاری، با کلید)
ava.custom.run(script)                                   // اجرای فرمان سفارشی تأییدشده
ava.voice.onToggleListen(cb)                             // رویداد میانبر سراسری
```

فرمان‌های واقعی فقط با «شناسه» از فهرست سفید `COMMANDS` در `main.js` اجرا می‌شوند (باز کردن برنامه، صدا، اسکرین‌شات، قفل، جستجوی وب و…)؛ این یعنی امنیت کامل و هیچ تزریق دستوری از لایه UI ممکن نیست.

### اتصال AI بدون کلید — چطور کار می‌کند؟

1. پنل چت، تب «صفحه چت GLM»: یک `<webview>` با `partition="persist:ai"` که `chat.z.ai` را نشان می‌دهد؛ کاربر یک بار لاگین می‌کند و نشست (کوکی + localStorage) دائمی می‌ماند.
2. توکن نشست با `webview.executeJavaScript("localStorage.getItem('token')")` خوانده می‌شود (فقط در حافظه نگه‌داری می‌شود).
3. «چت سریع» و مسیریابی سوالات پیچیده، همان توکن را به هندلر `ai:zaiChat` در پروسه اصلی می‌دهند که با آن `POST https://chat.z.ai/api/chat/completions` را صدا می‌زند (انتخاب خودکار مدل از `/api/models`، پشتیبانی از پاسخ SSE).
4. اگر کاربر کلید API GLM هم داشته باشد (اختیاری)، مسیر رسمی `api.z.ai` به‌عنوان پشتیبان استفاده می‌شود.
5. پاپ‌آپ‌های لاگین (OAuth گوگل و…) داخل برنامه باز می‌شوند؛ بقیه لینک‌ها به مرورگر سیستم می‌روند.

### نقشه راه نسخه‌های بعد

1. **Wake Word:** تشخیص کلمه‌ی «آوا» در پس‌زمینه + Tray icon.
2. **STT آفلاین:** Whisper / Vosk برای فارسی بدون نیاز به اینترنت.
3. **تنظیم دقیق درصد صدا** و کنترل روشنایی.
4. **مانیتور زنده سیستم** (آیکون‌های قفل‌شده سایدبار).

## نکات طراحی

- پالت: پس‌زمینه `#0a0e10`، تأکیدی `#10b981 → #34d399`، متن `#e7f0ea`
- افکت شیشه: `backdrop-filter: blur + saturate` به‌همراه هایلایت‌های داخلی (inset) و هسته‌ی مایع متحرک
- چیدمان RTL کامل؛ دکمه‌های پنجره مطابق عرف برنامه‌های راست‌به‌چپ در سمت چپ نوار عنوان قرار دارند (برای برگرداندن، فقط ترتیب `.tb-controls` در HTML را عوض کنید)
- در مرورگر (پیش‌نمایش وب) همه‌چیز شبیه‌سازی می‌شود؛ `window.ava` فقط داخل Electron وجود دارد
